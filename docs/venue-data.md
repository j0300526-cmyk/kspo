## 브라우저용 변환

`public/models/kspo-dome.glb`는 원본의 실제 삼각형과 계층 변환을 적용한 파생 시각화다. 새로 그린 가상 공연장이 아니다.

1. XML 외부 엔티티, DTD 로딩, 네트워크 접근을 비활성화해 파싱한다.
2. 원본 inches, Z-up 좌표를 metres, Y-up으로 변환한다.
3. 지붕 외곽의 수평 중심을 원점으로 이동한다. 변환식과 상수는 `venue-meta.json` 참조.
4. 많은 삼각형을 가진 재질 그룹을 원본의 약 18%로 단순화한다. 소규모 부품은 유지한다.
5. 원점에서 수평거리 80m 밖의 떨어진 표시물 및 중심이 지하 -0.25m 아래인 삼각형을 제외한다. 지표와 교차하는 일부 삼각형은 남는다.
6. 중심 높이 19m 이상인 삼각형을 `roof_` 메시로 분리한다. 나머지는 `bowl_` 접두어를 쓴다. 상부 구조를 통째로 의미 분류한 것이 아닌 높이 기준 분류다.
7. 텍스처를 제외하고 중립색으로 표시한다.

최종 모델은 약 18.5 MB, 973,724 삼각형, 91 메시다. 원본에는 상부 객석 및 낮은 계단식 객석 모듈이 포함되어 있다. 이들을 임시 평지 의자라고 단정할 근거가 없으므로 보존했다. 공개 모델의 좌석 배치는 현재 또는 특정 공연의 배치와 다를 수 있다. 실제 행사의 무대/장비 위치는 별도 사용자 입력이다.

## 관찰점 데이터

`public/models/observation-points.json`에는 7,478개의 반복 의자 등받이 부품에서 추출한 후 동일한 위치를 중복 제거한 **7,382개 관찰점**이 있다.

- 선택한 원본 부품: `group_84`, `group_86`, `group_90`, `group_92`, `group_94`, `group_98`.
- 수평 위치: 부품의 세계좌표 bounding box 중심.
- 높이: 등받이 부품의 최고점 + **0.30m 가정값**.
- `G00001` 같은 ID는 앱에서 생성한 참조 ID다. 공식 구역·열·좌석 번호가 아니다.
- 실제 사람의 눈높이나 실측 좌석 좌표가 아니다. 반복 형상에서 얻은 설계 검토용 관찰 표본이다.
- 모든 좌석을 빠짐없이 복원했다는 의미가 아니다. 일부 다른 의자 형식과 바닥 의자는 추출하지 않았다.

공식 좌석 번호와 연결하려면 별도 좌석배치도 검증·매핑이 필요하다. 현재 결과는 예매 판단이나 안전 인증을 대신할 수 있는 실측 자료가 아니다.

## 재현

Python 3 환경에서 필요한 오픈소스 패키지:

```powershell
python -m pip install numpy lxml trimesh fast-simplification
```

원본 ZIP을 `assets-source/kspodome_dae.zip`에 다운로드하고 내부 DAE가 `assets-source/` 아래에 오도록 압축을 푼 뒤:

```powershell
python scripts/convert-venue.py
python scripts/convert-venue-finish.py
```

두 번째 명령은 첫 번째 명령이 생성한 원본 중심의 GLB와 관찰점에 **한 번** 적용한다. 재실행하려면 첫 번째 명령부터 실행한다. `--points-only`는 중간 검사 용도이며 배포용 파일을 완성하지 않는다.

## 확인한 사항

- 원본 ZIP CRC 검사 통과.
- GLB v2 헤더 및 바이트 길이 검사 통과.
- 관찰점 좌표의 유한성 검사 통과.
- 원본 모델이 렌더링용 삼각형으로 변환되는지 상부 평면 투영으로 확인.
- 삼각형 축소로 표면이 근사되므로 구조물 정밀 분석 시에는 원본과의 추가 검증이 필요하다.

## 바닥 높이와 무대 배치 좌표 확인

- 공개 모델의 바닥 메시 `bowl_ID224332`는 모든 정점 높이가 Y=0m이다. 범위는 X 약 -44.84~45.11m, Z 약 -45.52~44.43m이다. 이 범위 전체가 비어 있는 경기면이라는 의미는 아니다.
- 낮은 내부 형상(Y 0.1~6m) 중 중앙에서 가장 가까운 정점의 수평거리는 약 23.4m다. 중앙 X ±9m 띠 안의 낮은 내부 형상은 Z 약 -22.49m, +21.76m에서 시작한다. 이는 단순화한 모델 정점으로 계산한 참고 범위이며 실측 경기장 규격은 아니다.
- 기본 무대를 중심 [0,0,-16], 폭18m, 깊이8m, 높이1.5m로 둘 때 수평 범위는 X ±9m, Z -20~-12m이고 네 모서리는 반경 약21.93m 이내다. 따라서 공개 모델의 중앙 열린 영역 안에 들어가며 무대 바닥 Y=0이 일치한다.
- 이 확인은 모델 좌표 정합성 검토다. 소방 동선·대피·구조 안전·공연장 대관 승인을 뜻하지 않는다.
